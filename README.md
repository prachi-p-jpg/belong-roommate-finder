# Belong — Roommate Finder (React)

A React + Vite implementation of the Belong roommate-finder UI.

## Pages
- `/` — Landing/Home
- `/preferences` — Preferences
- `/lifestyle` — Lifestyle Preferences
- `/search-results` — Search Results
- `/listing/1` — Listing Details
- `/saved` — Saved Homes
- `/profile` — My Profile
- `/mobile-home` — Mobile Home preview
- `/mobile-listing` — Mobile Listing preview

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Run:
   `npm install`
4. Start:
   `npm run dev`
5. Open the URL shown by Vite.

The UI uses React Router and Lucide React icons. Listing images are loaded from Unsplash URLs; replace them with local assets when you connect the project to a backend.
